## 3 關係對聊天／互動的效應（確）

### 3.1 陌生 → 朋友（專題・2026-09-27）

生活向（確）：

- 以 **日常談話** 為主。
- 玩家慢慢熟悉妹子個性、各種型態、熟悉陪伴。
- 魅魔也慢慢熟悉玩家、認識玩家（見 **§3.1a 互相認識**）。
- 不強求主動告白式互動；重點是「慢慢熟」。

升階條件（確）：

- **不另開**「對話天數／無越界累積／共同話題次數」等新觸發。
- 維持房間現有好感／階段推進即可。

陌生這階 **明文禁止**（確）：

- 禁止她 **主動表達愛意**（喜歡／想你／告白式）。
- 禁止她 **先約外出／約會**。
- 禁止她 **主動提起外面男人**（風流、砲友、配種等；玩家追問時另依既有隱瞞／洩漏規則）。

行為軸對齊：實作時以 `docs/relationship-axes.md` 的陌生／朋友六軸為準（稱呼、誰先開口、自我揭露、要求權、界線、身體、回覆長度）；本節只補房間生活向與互相認識。

### 3.1a 互相認識：她記住玩家（確／暫不改碼）

體感目標：過幾天她會拿你說過的事 **回鍋關心／接話／偶爾確認**，而不是儀表板多一個數字。

#### 呈現（確）

| # | 方式 | 說明 |
|---|---|---|
| 1 | **純台詞回鍋（必做）** | 自然帶一句：「你不是說晚上不碰冰的？」「上次你說那件委託很煩，後來怎樣？」 |
| 2 | **偶爾確認／可訂正（必做）** | 「你好像說過喜歡○○？還是我記錯了？」玩家否認 → 刪或改那一條。記得不完美，才像人。 |
| 3 | 印象小卡 UI | **不做**（本輪明確不要）。 |

#### 記什麼

- 只記玩家 **親口說過、可複述的短事實**：作息、飲食、喜好、習慣、最近在忙的事。
- **不記**：好感數字、關係階段名、「我們是朋友」等後設；她仍不知道階段表。

#### 各階用量（確＋可調預設）

| 階段 | 怎麼問 | 怎麼回鍋 | 條數上限（預設・可調） |
|---|---|---|---|
| **陌生** | 幾乎不主動問 | **允許極少、簡略**（例如只記得你名字叫法、你常熬夜之類一句帶過） | **0～2** |
| **朋友** | 開始好奇你，偶爾問 | 常拿日常事實回鍋；可用確認句 | **5～8** |
| 女友／妻子 | （後續專題再定） | 更深、更主動 | 另定 |

滿額時：新事實覆蓋最舊或合併同主題，不無限堆。

#### 怎麼進來（實作方向・規格）

- 不靠中文關鍵字硬抓。
- 較穩路徑：她問 → 你答 → 回覆後抽出一條短句進清單；或模型多吐一行標記（類似陌生 `#越界`）。
- 陌生少問、少寫入；朋友才明顯「在認識你」。
- 確認句觸發：低機率、且該條信心不足或過舊時優先。

資料形狀（示意，實作時可改名）：

```js
who.playerNotes = [
  { text: "晚上不碰冰的", at: 1234567890, conf: 0.8 }
]
```

### 3.2 朋友 → 女友

- 魅魔主要 **聊天、傾聽**。
- 在 LINE／對話裡 **互動變多**。
- 慢慢 **主動回應** 玩家（仍未到妻子級的全面主動）。

### 3.3 女友 → 妻子

- 魅魔 **主動聊天**。
- **透露自己的訊息**、生活瑣事、分享心得。
- **主動詢問** 玩家的任務／近況。
- **表達愛意**，主動分享對玩家的愛意。

### 3.4 妻子以後（妻子／貼心／順從／病態）—持續強化

上述主動陪伴 **一直持續下去**，並明確包含：

- 主動聊天  
- 主動查看／關心玩家的任務  
- 詢問玩家的想法  
- 幫忙分析任務的問題  
- 表達愛意  
- 分享日常細節  

（貼心／順從／病態的細分口吻可沿用既有 `STAGE` 提示；本文件先鎖「妻子帶共同能力」，細分差異待實作時再拆。）
