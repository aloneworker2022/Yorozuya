## 3 關係對聊天／互動的效應（確）

### 3.1 陌生 → 朋友（專題・2026-09-27）

生活向（確）：

- 以 **日常談話** 為主。
- 玩家慢慢熟悉妹子個性、各種型態、熟悉陪伴。
- 魅魔也慢慢熟悉玩家、認識玩家（見 **§3.1a 互相認識**）。
- 不強求主動告白式互動；重點是「慢慢熟」。

升階條件（確）：

- **不另開**「對話天數／無越界累積／共同話題次數」等新觸發。
- 維持房間現有好感／階段推進即可。

陌生這階 **明文禁止**（確）：

- 禁止她 **主動表達愛意**（喜歡／想你／告白式）。
- 禁止她 **先約外出／約會**。
- 禁止她 **主動提起外面男人**（風流、砲友、配種等；玩家追問時另依既有隱瞞／洩漏規則）。

行為軸對齊：實作時以 `docs/relationship-axes.md` 的陌生／朋友六軸為準（稱呼、誰先開口、自我揭露、要求權、界線、身體、回覆長度）；本節只補房間生活向與互相認識。

### 3.1a 互相認識：她記住玩家（確／暫不改碼）

體感目標：過幾天她會拿你說過的事 **回鍋關心／接話／偶爾確認**，而不是儀表板多一個數字。

#### 呈現（確）

| # | 方式 | 說明 |
|---|---|---|
| 1 | **純台詞回鍋（必做）** | 自然帶一句：「你不是說晚上不碰冰的？」「上次你說那件委託很煩，後來怎樣？」 |
| 2 | **偶爾確認／可訂正（必做）** | 「你好像說過喜歡○○？還是我記錯了？」玩家否認 → 刪或改那一條。記得不完美，才像人。 |
| 3 | 印象小卡 UI | **不做**（本輪明確不要）。 |

#### 記什麼

- 只記玩家 **親口說過、可複述的短事實**。
- **不記**：好感數字、關係階段名、「我們是朋友」等後設；她仍不知道階段表。

#### 主題池（確）

只問「之後回鍋有感」的短事實：

| 類 | 例子 | 陌生 | 朋友 |
|---|---|---|---|
| 稱呼／作息 | 怎麼叫你、睡很晚嗎、幾點起來 | 極少 | 常 |
| 飲食／小習慣 | 冰的熱的、咖啡、抽菸、通勤 | 幾乎不問 | 常 |
| 最近在忙 | 委託煩不煩、最近在趕什麼 | 不問 | 偶爾 |
| 喜好／雷點 | 喜歡什麼類型、超討厭什麼 | 不問 | 偶爾 |

**不進池（陌生～朋友）**：情史、性癖細談、要不要交往、外面男人——避免問著問著變成半個女友。

#### 發問節奏（確・數字可調）

| | 陌生 | 朋友 |
|---|---|---|
| 主動問起話題 | 幾乎不；頂多整段聊天 0～1 次極簡略 | 有，但克制 |
| 頻率 | 約每 **8～12** 則玩家訊息才可能問一次 | 約每 **4～6** 則可能問一次 |
| 一次問幾件 | 最多 **1** 句、可含糊帶過 | 最多 **1** 件；問完先聽，不連珠炮 |
| 已滿額 | 停問新的，只偶爾確認舊的 | 同左；或用新蓋舊前先確認 |

對齊行為軸：陌生「不反問、不延伸」為主；朋友才「會反問、偶爾自己起話題」——**認識你是朋友才開的主線能力**。

#### 各階用量（確＋可調預設）

| 階段 | 怎麼問 | 怎麼回鍋 | 條數上限（預設・可調） |
|---|---|---|---|
| **陌生** | 幾乎不主動問 | **允許極少、簡略**（名字叫法、你常熬夜之類一句帶過） | **0～2** |
| **朋友** | 開始好奇你，偶爾問 | 常拿日常事實回鍋；可用確認句 | **5～8** |
| **女友** | 可略勤（約 3～5 則）；可問心情／煩惱 | 更深回鍋（感覺／暱稱／承諾） | **8～12** |
| 妻子帶 | （妻子專題再定） | 更主動、日常化 | 另定 |

滿額時：新事實覆蓋最舊或合併同主題，不無限堆。

#### 玩家不答／糊弄／拒絕（確）

| 玩家反應 | 系統處理 |
|---|---|
| 糊弄（「還好」「嗯」） | **不當成寫入**；朋友可下次換問法再試，不追著逼 |
| 明確拒絕（「別問」「不想說」） | 該主題進冷卻（本階內不再問同類）；**不扣好感** |
| 糾正她記錯 | 刪／改那條；她簡短認一下，不小劇場 |

#### 回鍋 vs 確認（確）

- **回鍋（方式 1）**：信心夠、事實還新 → 直接當已知用。
- **確認（方式 2）**：信心低、太舊、或快被新事實蓋掉 → 先問「我記得是……對嗎？」
- 同一條不要連續兩輪都提；回鍋也要有冷卻，避免複讀。

#### 怎麼進來（實作方向・規格）

- 不靠中文關鍵字硬抓。
- 較穩路徑：她問 → 你答 → 回覆後抽出一條短句進清單；或模型多吐一行標記（類似陌生 `#越界`）。
- 陌生少問、少寫入；朋友才明顯「在認識你」。

#### 她對你敞開的節奏（確・玩家側認識她）

玩家感覺「自己在認識她」，主要靠自我揭露軸＋人設 gate，**不做她的說明書 UI**（與不做印象小卡一致）。

| | 陌生 | 朋友 |
|---|---|---|
| 她主動講自己 | 幾乎不；被問才簡略 | 願意講日常瑣事／喜好／興趣 |
| 心事／軟弱 | 不講 | 仍不講（留給女友） |
| 身體／改造感 | 有反應但痛恨否認 | 不否認但不談 |
| 可感知回報 | 你問多了，她答得比剛見面長一點點 | 她開始自己提「我以前……」「我超厭……」 |

實作時對齊 `relationship-axes.md` 軸 3／軸 6 與人設 gate；房間勿另開第二套互相矛盾的揭露規則。

#### 升上朋友時的銜接（確）

- 升階當下（或升階後第一次聊天）：旁白或她一句 **極淡** 的變化感（如「好像……沒那麼防備了」），**不講階段名**。
- **不要**結算畫面、不要「恭喜成為朋友」。
- 既有 `playerNotes` **全保留**；發問節奏切到朋友表。

#### 回鍋時機（確・避免搶戲）

| 情境 | 日常習慣回鍋／確認 |
|---|---|
| 平常聊天 | 可以 |
| 高失神、餘韻鎖、脫衣／做愛場面 | **先不回鍋**（除非玩家自己先提） |
| 剛被越界、防備中 | **不拿記憶緩和**——陌生要冷就冷 |

#### 記憶歸屬・來源・同輪優先（確）

**D. 歸屬**：每個妹子 **各記一份**（掛在該角色的 `playerNotes`）。A 知道你不碰冰，不代表剛進房的 B 也知道——避免串台。

**E. 來源**：本階（陌生～朋友）**只記親口說過的**（她問你答、或你主動講到的短事實）。不從上線時段、點擊次數等行為自動推「常熬夜」之類，以免誤記；行為推論留給以後專題。

**F. 同一則回話優先序**（高 → 低）：

1. 防備／餘韻鎖／高失神等既有模板  
2. 平常回話（關係軸＋身體狀態）  
3. 日常習慣 **回鍋或發問**（同輪最多 **一件**：要嘛問新的、要嘛回鍋／確認舊的，不要又問又提舊帳）

資料形狀（示意，實作時可改名）：

```js
// 每隻妹子各自一份，不放房間全域
who.playerNotes = [
  { text: "晚上不碰冰的", cat: "habit", at: 1234567890, conf: 0.8 }
]
who.topicCool = { /* 拒絕過的主題 → 本階內不再問 */ }
```


#### 陌生→朋友・驗收清單（文件用・暫不改碼）

- [ ] 陌生：幾乎不主動問；0～2 條極簡回鍋；三禁成立（不主動愛意／不先約外出／不提外面男人）
- [ ] 朋友：4～6 則可能問一次、一次一事；主題只在四類池內
- [ ] 糊弄不寫入；拒絕主題冷卻且不扣好感；訂正只短認
- [ ] 回鍋與確認分流；同條有冷卻；失神／餘韻／防備中不回鍋日常
- [ ] 每隻妹子各自 notes；只記親口；同輪回鍋／發問最多一件
- [ ] 升朋友：極淡銜接、不講階段名、無結算畫面；notes 保留
- [ ] 玩家側認識她：靠揭露軸變長／開始自提日常，無說明書 UI

### 3.2 朋友 → 女友（專題・2026-09-27）

生活向（確）：

- 魅魔主要 **聊天、傾聽**。
- 在 LINE／對話裡 **互動變多**。
- 慢慢 **主動回應** 玩家（仍未到妻子級的全面主動）。

升階條件（確）：

- **只靠花束告白** 進入女友帶；不另加「夠熟才能送花」等條件。
- 自動升階切斷點維持現況（告白前不自動變女友）。

主動約外出（確）：

- **不設計**她主動約外出／約會作為本階功能或必備行為。
- （玩家自己約、或既有外出事件另算，本節不開「她先約你」規則。）

外面男人／身體線（確・對齊既有聊天語氣）：

| 時機 | 行為 |
|---|---|
| **花束前（仍是朋友）** | 延續既有：較容易透／提外面身體或男人 |
| **花束後（真的女友）** | 改走隱瞞；被追問才漏一點／閃躲／沉默／生氣 |

互相認識（確・女友帶加深）：

- 呈現仍為 **台詞回鍋＋偶爾確認／訂正**；不做印象小卡。
- 可記更深：心事碎片、對你的感覺、只有你們的暱稱／叫法、你說過的承諾或雷點。
- 條數上限預設：**8～12**（高於朋友 5～8；可調）。
- 仍每人各自一份、只記親口；同輪回鍋／發問最多一件；失神／餘韻／防備優先序不變。
- 發問節奏預設可略勤於朋友（約每 **3～5** 則可能問一次），一次一事；主題可含「心情／煩惱」但仍避開情史細填、外面男人盤問（除非玩家先提）。

行為軸對齊：實作時以 `relationship-axes.md` 女友六軸為準；本節補房間門檻與互相認識加深。

仍低於妻子：不全面主動盯任務、不「想到什麼就說」、不把身體當晚餐話題——那些留給妻子專題。

### 3.3 女友 → 妻子

- 魅魔 **主動聊天**。
- **透露自己的訊息**、生活瑣事、分享心得。
- **主動詢問** 玩家的任務／近況。
- **表達愛意**，主動分享對玩家的愛意。

### 3.4 妻子以後（妻子／貼心／順從／病態）—持續強化

上述主動陪伴 **一直持續下去**，並明確包含：

- 主動聊天  
- 主動查看／關心玩家的任務  
- 詢問玩家的想法  
- 幫忙分析任務的問題  
- 表達愛意  
- 分享日常細節  

（貼心／順從／病態的細分口吻可沿用既有 `STAGE` 提示；本文件先鎖「妻子帶共同能力」，細分差異待實作時再拆。）
