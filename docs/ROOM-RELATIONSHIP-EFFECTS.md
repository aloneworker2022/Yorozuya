## 3 關係對聊天／互動的效應（確）

### 3.1 陌生 → 朋友

- 以 **日常談話** 為主。
- 玩家慢慢熟悉妹子個性、各種型態、熟悉陪伴。
- 魅魔也慢慢熟悉玩家、認識玩家。
- 不強求主動告白式互動；重點是「慢慢熟」。

### 3.2 朋友 → 女友

- 魅魔主要 **聊天、傾聽**。
- 在 LINE／對話裡 **互動變多**。
- 慢慢 **主動回應** 玩家（仍未到妻子級的全面主動）。

### 3.3 女友 → 妻子

- 魅魔 **主動聊天**。
- **透露自己的訊息**、生活瑣事、分享心得。
- **主動詢問** 玩家的任務／近況。
- **表達愛意**，主動分享對玩家的愛意。

### 3.4 妻子以後（妻子／貼心／順從／病態）—持續強化

上述主動陪伴 **一直持續下去**，並明確包含：

- 主動聊天  
- 主動查看／關心玩家的任務  
- 詢問玩家的想法  
- 幫忙分析任務的問題  
- 表達愛意  
- 分享日常細節  

（貼心／順從／病態的細分口吻可沿用既有 `STAGE` 提示；本文件先鎖「妻子帶共同能力」，細分差異待實作時再拆。）
