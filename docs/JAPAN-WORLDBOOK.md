## 使用原則

日常背景：住家垃圾依當地分類和收集日；電車內放低音量，排隊候車；買東西、洗衣、帶傘、等車都是生活，不必每趟打卡。只取與當前事件相容的一兩個細節，不堆景點或強加天氣。來源是地理背景，生活描寫是創作素材；怪事只屬虛構劇情，不宣稱真實地點鬧鬼。實際票價、營業時間、天氣、祭典是否正在舉行未知，不可憑空寫死。這是她自己的經歷，不要求發 LINE 或找群友討論。

名勝與地域背景參考各節 JNTO 官方來源，查閱日期 2026-11-28。街景感受與日常動作是原創寫作素材，不是旅遊機關逐字記錄，也不是保證會發生的事。季節表示可能景象，沒有接入即時氣象、交通、活動或營業 API。

每次生活結算只放入當前地區的一筆世界書，不把整本塞進 prompt。旅遊先換目的地 groundId、regionId、spots 再抽事件；原住處不變。原始已排定 agenda.event 不重抽，下一次新事件才採新資料。

## 日常生活的尺度

一天不需要跑遍名勝。下班買菜、忘記帶傘、洗衣等乾、搭錯出口、挑一份便當，都可以是一段完整生活。角色只使用自己經歷過的內容，世界書本身不是已完成的旅遊紀錄。

住宅垃圾分類以所在自治體為準，不編造統一收集日；用餐、候車與寺社禮儀依場所，不把所有日本人套成同一種性格。當前工作是主要情節時，世界書只提供周邊氣氛，不強迫她離開工作去景點。

## 異常擴充與敘事原則

原本 31 組 SCP、155 段。本次增加 4 組 SCP 生活改編與 12 組原創異聞，共 47 組、235 段。不是把遇事機率提高成天天撞鬼；沿用首次基礎 1/12、續篇 1/3 及情緒等修正，事件間隔 2～4 天，完成五段後不從頭重播。

新增故事沿著線索、重遇、矛盾、抉擇、痕跡發展。怪事結束不代表知道全部真相；她可以自己記住，沒有新增強制群聊或公告。離線範本也使用當段線索，不再五段都回同一句。記錄仍走現有 memories 與 scpSteps，沒有另外偷偷改人物數值或加戰鬥。

SCP 原條目與本遊戲改編不同；來源、作者、衍生授權見 [SCP-ATTRIBUTION.md](SCP-ATTRIBUTION.md)。其他十二組不是歷史民俗或真實鬧鬼宣稱。

### SCP-303・門後的喘息

觸發範圍：一般外出；打工；

1. 儲物間門後傳來沉重喘息，明明手上有鑰匙，她卻突然害怕得握不住把手。
2. 隔幾天同一種喘息出現在另一道門後；她沒看過它，腦中卻清楚浮出一張滿是牙的嘴。
3. 她隔著玻璃門尋找聲音，玻璃恰好起霧，只露出一小片影子；她仍無法推門。
4. 另一位值班者從側門靠近時喘息停止，她的手也恢復能動；沒有人看見它離開。
5. 門後不再有聲音，她把安全的另一個出口位置記進手機；以後進陌生房間會先找第二道門。

### SCP-507・說到一半消失的旅人

觸發範圍：一般外出；

1. 一個陌生成年旅人正在問路，說到半句突然消失；她端著沒遞出去的紙杯站在原地。
2. 再遇到他時，他穿著不合季節的衣物，先確認這裡的天空顏色，堅稱不是故意失約。
3. 他描述另一個世界同一位置的景象，說自己無法決定何時離開；她只聽，沒有碰他。
4. 他剛想道謝又在句中消失，留下她還記得的半句話；不要讓她取得控制穿越的能力。
5. 最後一次見面他平安回來，終於把那句謝謝說完；她記住他只是想安穩喝完一杯水的人。

### SCP-372・視線邊緣的細腳

觸發範圍：一般外出；打工；

1. 她在視線邊緣看到細長的腿，轉頭時卻只剩牆面；沒有任何抓傷。
2. 她試著慢慢轉頭，黑影仍恰好滑進看不見的角度，像比她更早知道眼睛要往哪裡動。
3. 同行者面向她背後時也看見一閃而過的細腳，兩人看到的方向始終不一樣。
4. 她把手機固定拍攝，自己不追著影子轉頭；畫面角落出現極短的輪廓，無法看清全貌。
5. 接下來再沒有看見細腳，但那一格模糊影像仍留在手機；她沒有證據說它已經被消滅。

### SCP-002・外面沒有的窗

觸發範圍：打工；

1. 搬運時看到一個帶金屬艙門的異常物，門內竟是小公寓；她站在門外，沒有進去。
2. 再去時她發現室內有窗，繞到外面卻完全找不到相應的開口。
3. 照片中的室內家具比上次多了一件，但搬運記錄沒有任何家具送入。
4. 同事靠近門口時忽然沉默，她拉對方後退，確認兩個人都還在；不描寫人體材質或傷害。
5. 區域被封閉，她保留那張內外窗戶對不上的草圖；不知道裡面最後怎樣，只記得自己沒進門。

### 異聞・明天的收據

觸發範圍：一般外出；打工；

1. 她買一瓶茶，收據卻多出一項她尚未買的雨傘，日期印著明天。
2. 下一次出門下雨，她在別家店買傘，金額恰好與那張收據一致。
3. 新收據印著一把陌生門鎖的鑰匙，店員說貨架上根本沒有這件商品。
4. 她拒絕依照收據找鑰匙，紙上金額卻逐漸變成她身上所有零錢的總和。
5. 她沒有付款，收據隔天褪成白紙，只有自己折出的摺痕還在；從此會核對明細再離店。

### 異聞・以她命名的終點

觸發範圍：一般外出；

1. 站牌最下面多了一個沒聽過的站，字形像她名字的第一個字。
2. 數日後再看，新增站名已經完整變成她的名字；別人的路線圖卻沒有這一站。
3. 末班車靠站，車內播報用她的聲音說『下一站，到家了』，但車上沒有人。
4. 她往亮著燈的商店走去，車門一直等著，直到她把自己的住址清楚寫在紙上才關閉。
5. 站名恢復正常，她留下住址紙條；偶爾等車時仍先確認目的地，不把這件事講給所有人聽。

### 異聞・先離開的倒影

觸發範圍：大阪・道頓堀、金澤、神戶、倉敷・美觀地區

1. 河邊玻璃上的倒影比她早半拍收起手機，她以為只是眼花。
2. 她特意站定不動，倒影卻整理衣領，像在等她跟上。
3. 倒影朝另一條巷子走，她本人仍留在原地；玻璃裡只剩沒有人的街。
4. 下次路過時倒影從巷口回來，掌心貼著玻璃，示意她別走那條路。
5. 倒影重新與她同步，玻璃上留下朝外的掌印；她沒得到解釋，只換了一條回程路。

### 異聞・多出來的乾衣

觸發範圍：一般外出；

1. 投幣洗衣機停下後多了一條不屬於她的白毛巾，摸起來還溫熱。
2. 她把毛巾放進失物籃，下次洗衣卻又出現在自己那一桶裡，折法完全相同。
3. 毛巾角落繡出了她剛搬來那天的日期，店員說失物籃裡一直是空的。
4. 她在籃裡留下『不是我的』，隔天紙條背面多了『現在還不是』。
5. 毛巾不再出現，她留著紙條，洗完衣會多數一次；沒有新增一段她不曾經歷的失憶往事。

### 異聞・只到窗下的腳印

觸發範圍：札幌・薄野、青森市、函館・元町、輕井澤

1. 她看見地面一串濕腳印朝窗下延伸，沒有離開的痕跡，也沒有敲門聲。
2. 再遇到時每個腳印都小了一點，終點仍是同一扇窗。
3. 腳印尺寸變得和她的鞋底相同，但她當天根本沒走過那條路。
4. 她在窗內看見外頭腳印逐枚出現，順序是從窗下往遠處倒著生長。
5. 痕跡最後停在街角消失；她拍下鞋底作對照，之後下雨回家會先擦乾鞋子。

### 異聞・沒有那一格的鑰匙

觸發範圍：打工；松山・道後溫泉、箱根溫泉、草津溫泉、熱海、伊豆・修善寺

1. 她領到一把鞋櫃鑰匙，號碼卻比現場最後一格多一號；工作人員換了一把給她。
2. 下次來時同一把多出的鑰匙又掛在手腕上，掌心有自己握出的印子。
3. 櫃列末端出現一道極窄的門縫，裡面傳來木屐聲，卻沒有走廊空間。
4. 門縫裡有人輕聲報出她還沒領走的鞋子顏色，她不開門，向櫃檯要回自己的鞋。
5. 她歸還鑰匙後門縫消失；鞋底夾著一小張空白號碼牌，她把它留在收據袋裡。

### 異聞・照片裡晚一拍的鐘

觸發範圍：札幌・薄野、松山・道後溫泉、函館・元町、名古屋・大須

1. 她拍下街景，照片裡的鐘比現場慢一分鐘，手機時間卻正常。
2. 幾天後再拍，同一面鐘慢了一小時，背景行人也穿著不合當季的衣物。
3. 舊照片裡多了一個背對鏡頭的自己，站在她拍照時的位置。
4. 她停止拍攝，舊照片中的自己卻轉過身，舉起手指向畫面外；不揭露另一個人的命運。
5. 她把照片封存，鐘在新拍的普通街景裡恢復正常；她不再拿鏡頭試探那面鐘。

### 異聞・提前回答的回音

觸發範圍：京都・東山、奈良、日光、東京・淺草

1. 走在有屋簷的小巷，她還沒開口就聽見一聲和自己相同的『不好意思』。
2. 她故意不說話，回音卻替她把原本想問的路問完。
3. 她改問完全不同的問題，回音停頓後回答了她心裡不願說出的那一個。
4. 巷子深處開始排練她明天可能說的道別，她中途走回人多的街上，沒有答應赴約。
5. 此後只剩正常腳步聲，她把想說的話自己寫進筆記；那些預演沒有被當成已發生的事。

### 異聞・沒有開出的船票

觸發範圍：沖繩・那霸、神戶、函館・元町、青森市、熱海

1. 港邊售票機吐出一張沒印航線的票，背面只有一條鉛筆畫的岸線。
2. 她再去問時沒人認得票種，岸線卻多畫了一盞與碼頭相同的路燈。
3. 票上又出現一個站在燈下的人影，衣服和她當天一樣。
4. 停用的登船口傳來驗票聲，她留在欄杆外；票上的人影卻已經走進畫中的船。
5. 她沒有登船，票面在晨光裡淡去，只留一個從未打過的孔；以後會先核對真正航線。

### 異聞・比建築多一層

觸發範圍：一般外出；打工；

1. 樓梯告示寫三層，她走到頂卻看見寫著四樓的指示牌，門上落著灰。
2. 下次來她從外面數窗戶，確實只有三層；樓內的四樓牌仍在。
3. 四樓門縫透出和一樓同樣的收銀聲，但每次都比樓下早報出下一位客人的金額。
4. 樓下忽然報出她的名字，樓上那道門開始往內開；她沿原路下樓，不去看房間內部。
5. 建築整修後只剩三層，舊照片裡指示牌還在；她把樓層數記下，沒有憑空找到真相。

### 異聞・雲底下的另一座山

觸發範圍：富士五湖、箱根溫泉、日光

1. 湖面倒映一座山，山頂形狀與眼前真正的山不一致。
2. 她換到另一處湖岸，倒影的山始終保持同一角度，像固定在湖底。
3. 倒影山腰亮起一列燈，岸上卻沒有對應的道路或建物。
4. 燈一盞盞朝她的倒影靠近，她退出水邊；不要讓她踏進湖中或獲得超能力。
5. 湖面恢復普通倒影，她在筆記畫下那座山；天氣晴朗時仍會先看真正的山再看水面。

### 異聞・寄件人是未來的自己

觸發範圍：一般外出；

1. 她收到一個只裝著空白明信片的包裹，寄件人寫著自己的名字。
2. 再收到時明信片多了一幅她昨天才經過的街景，郵戳日期卻在之前。
3. 第三張寫著一句她只在心裡想過的抱怨，字跡和她相似但筆順不對。
4. 她把空白回郵封留著，沒有寄出；包裹外忽然浮出『不用回信，我知道了』。
5. 包裹停止，最後留下的是一張完全正常的當地風景；她把它與怪信分開收好。
