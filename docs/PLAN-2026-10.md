## 1 願景

真實 Todo 驅動的成人 PWA：玩家把現實待辦丟進來 → 完成賺金幣 → 召喚魅魔 → **在玩家自己的房間裡**陪伴、聊天、身體互動、關係慢慢長大。（確）

- **房間系統是核心**（確）：名冊付費「召喚」＝把她帶進主畫面中下方的像素房間，長按她聊天／互動。舊的遠距感應聊天、淫紋全螢幕聊天、看板打牌、主線約會入口都已退出玩家主路徑。

- 一句話方向（沿用交接書）：**玩家帶著自己的生活來找她，她也帶著自己的生活來找玩家；在玩家的房間裡慢慢形成有延續的關係。**

```

        → LLM 判定 接住 +5／喜歡 +3／有趣 +1／平常 0／冒犯 0（仍設防備）、身體事件加感情 → 房間 11 階關係

```

## 11 開發慣例

1. 先 `git pull`；**使用者的程式是權威**，不要覆蓋使用者本機或遠端的新工作；不要 force push。
