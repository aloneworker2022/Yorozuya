## 0. 這場約會在算什麼

| 欄位 | 玩家看到的意思 | 機械 |
|---|---|---|
| 地點 | 這一拍互動的內容從哪裡抽 | 場景底下很多個區域；開場在廣場 |
| 體力 | 還能按幾次 | 互動／調戲／猥褻 −1；**歸零 → 結束約會**。吃東西回復 |
| 性慾 | 加在感情上的級數；也進順從度 | 上限 **20**。互動時感情 = `1 + 0～性慾` |
| 羞恥 | 滿了她就跑；也進順從度 | 上限 **15**。全滿 → 跑掉結束 |
| 感情 | 這場約會養出來的好感 | **沒有上限**，只顯示數字 |
| 順從 | 只對男子有效 | **性慾 + 羞恥**。抗拒 0～10／回應 11～20／順從 21～35 |
| 金錢 | 吃東西要花 | 花費依場景／時段 |

玩家按鈕（正式畫面）：**互動／調戲／猥褻／吃東西／回家**  
（後台不算玩家操作。回家＝結束約會。）

固定加減：

- 互動：感情 `+1 + random(0～性慾)`，體力 −1
- 調戲：性慾 +1、羞恥 +1，體力 −1
- 猥褻：性慾 +3、羞恥 +5，體力 −1
- 吃東西：扣金錢（依場景／時段），**回復體力 2～4**。不扣體力。
- 回家：就是散場。不抽事件。
- 互動／調戲／猥褻之後：**1/4** 換到下一個地點（機率已鎖；畫面上怎麼演，跟後面呈現方式一起定）

散場條件（①算完就知道，③演完再切）：

- 玩家按「回家」
- 體力歸零
- 羞恥全滿（她跑掉）

做愛：男子線會碰到（順從＋性慾滿／男子強邀）。玩家自己的做愛特殊場景仍先不做。

時段：早上／下午／晚上／深夜（玩家不能選，系統進場時定）。  
卡要標時段：早晨卡只有早上抽得到。  
每張卡還要標 **羞恥低／中／高** 與 **性慾低／中／高**。抽卡只進「地點＋時段＋當下羞恥等＋當下性慾等」的池。

三等切點（暫定）：

| 等 | 性慾（0～20） | 羞恥（0～15） |
|---|---|---|
| 低 | 0～6 | 0～4 |
| 中 | 7～13 | 5～9 |
| 高 | 14～20 | 10～15 |

開場兩條都是 0，所以第一張一定是羞恥低＋性奮低。行動後數值變了，**下一張**才換池。羞恥到 10 會跑掉散場，不會再抽「羞恥高」之後的卡。

## 1. 普通事件怎麼演（鎖）

**行動是程式的，回應才是 AI 的。**  
人物 AI 只能對已經發生的事做反應，不能下達行動。

一張卡＝這個地點這一刻的**場景**（例如「廣場婆媽運動」）。  
卡上預寫四種行動的演法：互動／調戲／猥褻／吃東西。  
玩家先看到場景，再按按鈕；不是按了才抽「互動卡」。

```
進場地點固定＝廣場
        ↓
隨機判定誰先到（你先到／她先到／同時到）
        ↓
依判定演出碰面（你等她／她已經在／門口碰上）
        ↓
依「地點＋時段＋羞恥等＋性奮等」抽一張場景卡
        ↓
旁白把卡的場景講出來
（例：廣場上很多人在運動，尤其是阿公和老人）
        ↓
系統排出登場順位（例：玩家 → 女子 → 召喚師）
        ↓
等玩家按：互動／調戲／猥褻／吃東西／回家
        ↓
① 程式先算     扣體力、感情、性奮、羞恥（回家不抽、不演）
        ↓
② 旁白依卡上這個行動的預設演出
        ↓
③ 玩家那句上畫面     卡怎麼寫就怎麼出
   （例 我：你要不要跟他們一起運動啊。）
        ↓
④ 下一個順位的人 AI 反應（女子看：卡＋旁白＋玩家那句＋運算後數值）
        ↓
⑤ 再下一個人（召喚師若在場、排在順位裡）
        ↓
⑥ 判定：轉場（1/4 換地再抽）或抽下一張（原地新場景）
```

### 卡要長什麼樣

```
id: plaza_morning_exercise_sL_aL
zone: plaza
time: morning          # 只有早上抽得到
shame: low             # low / mid / high
arousal: low           # low / mid / high（性慾三等）
scene: 廣場上很多阿嬤阿公在運動
narration: 在廣場上很多人在運動，尤其是阿公和老人
cast: [player, girl, rival]
actions:
  interact:   # 每種行動 7 句，這場約會抽過的先不重複
    - { narr: 玩家看著運動的人，跟妹子說, player: 你要不要跟他們一起運動啊！ }
    - ...
  tease: [...]
  molest: [...]
  eat: [...]
```

按下互動之後：從 7 句裡抽一句還沒用過的。AI 旁白依 `narr` 幫忙演出；`player` 原樣當「我：」。  
女子／召喚師沒有卡上寫死的台詞——他們是 AI，只反應。

### 程式先算、AI 後說

按下去的當下就加減值。她開口時，體力／感情／性慾／羞恥已經是新的。  
AI 不准改這些數字，不准自己轉場、抽卡、回家。

## 3. 已對過

- 開場**沒有專用卡**。廣場固定進場 → **隨機誰先到**（你先／她先／同時）→ 碰面後再抽場景卡。
- 抽卡條件：地點＋時段＋**羞恥低中高**＋**性慾低中高**。同一場景這 3×3 都要有卡。
- 一張卡是場景，上面有互動／調戲／猥褻／吃東西四種預設演法。
- 玩家順位也由卡決定。按下後：AI 旁白依卡演出，**「我：」那句用卡上原文**。
- 程式先扣體力、算感情／性慾／羞恥，再讓下一個順位的人 AI 反應。
- 演完判定：**轉場（1/4 換地再抽）**或**原地抽下一張**。
- **AI 只反應，不行動。**
- 後一人看得到前一人剛說的話。
- 羞恥全滿 → 跑掉結束。體力歸零 → 結束。回家 → 結束。
- 吃東西：花錢、回復 2～4。
- 性慾上限 20，羞恥上限 15，感情無上限（只顯示數字）。

## 3.5 男子（測試場 100% 會有）

- 測試約會不擲「有沒有男子」。正式上線才在進場判定。
- 開場抽一種：噁心胖肥宅／健身變態男／色慾單身男。
- 玩家做完 **2～4** 個動作回合後才出場。進場第一句是**搭訕**（每種男一句，不是互動）。
- 男子在場時每回合：**男子 → 女子 → 旁白（雙方肢體／表情）→ 玩家選項（結束這回合）**。
- 男子在場時玩家按鈕改成 **帶女子脫離騷擾**／**吃東西**（互動／調戲／猥褻收起來）。玩家被晾在旁邊，不能照平常約會。
- 拉開跟 testdate 一樣不是每次都能成。開場 **1/15**，男子每互動一次分母 +2（1/17、1/19…）。越互動越難脫。成功則男子離開、換地；失敗下一回合他還在。
- 拉開成功後，之後每個玩家動作有 **1/3** 他又跟上。再出現**跳過搭訕**，該回合直接從男子動作開始。脫離機率接著上次的分母算。
- 之後每回合依喜好加權抽 **言語調戲** 或 **肢體碰觸**（表定 1/2，肥宅偏言語，另外兩個偏肢體）。
- 言語 +1 性慾 +1 羞恥；肢體 +2 +2。
- 順從度 = 性慾 + 羞恥。抗拒必失敗、回應 1/2、順從必成功。
- 男子在場時羞恥滿**不會散場**，她跑會被攔住。
- 順從且性慾滿：她主動問男子做愛，下一句對玩家說要去做愛（AI）。
- 順從時男子提／強邀，1/3 成功，下一句對玩家說我們要去做愛了（AI）。
- 台詞池：3 種男 × 11 張卡 × 3 等 ×（言語 5 + 肢體 5）＝ 990 句。
