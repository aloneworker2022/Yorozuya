# droom 備忘錄（2026-11-18）：畫頭——臉模＋五官的畫法（給後面的 AI）

這一輪和使用者一起從零做「頭」：先畫臉模（框），再一個一個加鼻子、眉毛、嘴巴。程式、樣品在 `face_mold/`（出圖指令看 `face_mold/README.md`）。**還沒接進遊戲**。眼睛還沒做。

這份重點是**畫法**：使用者怎麼要求、哪些做法被否定、要沿用的規則。接手畫頭（含之後的眼睛、頭髮、其他角度）一定先讀完。

---

## 一、工作方式（使用者要求，最重要）

1. **先畫一張給使用者看，確認了才往下做或做變化款。** 一次只改一件事；每次出圖都附「放大的特寫」和「整張」。
2. **使用者的參考圖、紅筆標註是權威。** 看不懂時把參考圖放大裁切來看（`PIL crop + resize`），量比例，不要猜。被糾正過的地方（見 §四）不要再犯。
3. **有疑問用「確認」的方式問，給 2～3 個選項**；不要自己改設計。
4. 出圖慣例：
   - 原尺寸 256×256 存一張，另外用最近鄰（NEAREST）放大 3 倍給整張、8～12 倍給特寫。
   - 三個角度並排（正面／左轉 45°／側臉）一起看；變化款排成表格並加中文標籤（字型 `wqy-zenhei.ttc`）。
   - 要看「乾淨的樣子」時關輔助線（`GUIDE=0`）；要對位置時開輔助線。

## 二、畫面規格（定案）

- **畫布 256×256 像素、像素畫**：每一格自己決定顏色，**不要用向量線、不要反鋸齒**（使用者否定過 900×900 向量線）。
- **只用三階肉色**（跟胸部模組同一套）：

  | 用途 | RGB |
  |---|---|
  | 肉色 | 242,204,177 |
  | 陰影 | 216,166,140 |
  | 深色 | 184,124,104 |

  五官另有自己的顏色（眉毛棕、嘴唇粉紅系，見程式常數）。
- **外框不描線**：碰到背景（白）的外框一律換成肉色，是平塗剪影（`three.py` 的 `noline()`）。
- **肉碰肉的地方也盡量不用線，改用陰影**（側臉下顎就是這樣改的，見 §三-6）。耳朵輪廓目前還是深色線。
- 光從**左上**來，影子放在右邊、下面。

## 三、畫法（由大到小，照這個順序）

### 1. 臉模的分段（先定比例，再畫形）

由上到下 4 段，橫線都是**定位用的輔助線**：

| 段 | 範圍 | 長度 |
|---|---|---|
| A | 頭頂 → **耳線**（＝眼睛中央那條線） | 固定，**佔全臉 3/5** |
| B | 耳線 → **鼻線**（鼻頭） | B＋C＋D 共 2/5，各 1/3 |
| C | 鼻線 → **嘴線** | |
| D | 嘴線 → 下巴 | |

- 數字：頭蓋圓半徑 R=70、圓心 y=120（畫布中央 x=128）；耳線＝圓心＋18；A＝88；B／C／D 各 88×2/9≈19.6。
- **使用者的範例（三排：耳朵／BOCA／NARIZ）是三個步驟**：①定中線和耳朵位置 ②下 1/3 定嘴巴和下巴 ③上 1/3 定鼻子和臉部轉折。不要把第一步的紅點（耳朵位置）當成轉折點。
- 變化：B、C、D 各有 短 ×0.8／中／長 ×1.2（`draw(kB,kC,kD)`），**寬度不跟著變**。
- 耳朵：上端在耳線上面一點，下端在轉折點（鼻線兩端）。

### 2. 正面臉框

頭蓋上半圓 → 兩側幾乎直直往下（微微內收）到**轉折點**（鼻線兩端，離中線 61）→ **直線**到嘴線（寬 43）→ 從嘴線**收圓**到下巴。

- 下巴**不要尖**，也不要整個圓成蛋形：嘴線以上是直線（使用者畫的紅線），嘴線以下才收圓。
- 脖子細（半寬 19），從下巴後面出來。

### 3. 左轉 45°（臉朝畫面左）

**做法：把正面當基準做一個簡單的 3D，轉 45° 再投影**（`turn45.cjs`），這樣各段高度和正面完全一樣。

- 頭蓋＝球；下半臉每一列＝橢圓切片：寬＝正面那一列的半寬，前＝臉中線深度（額 70 → 鼻 64 → 嘴 55 → 下巴 40），最寬處深度 z0 與後緣 zb 在鼻線以下往前收。
- 每一列取左右最遠的點當輪廓；遠側耳線附近加一個小凹（眼窩）。
- **下顎「打角度」，不是收尖**：近側從轉折點（耳朵下端）往下到**下顎角**，再轉往前到下巴。
  - 下顎角在**頭寬的 1/4**（從後腦那邊量進來；使用者說 1/3 太多）。
  - 高度在轉折點→下巴的 62%。
- **下顎線不要死板的折線**：耳下段微鼓、下顎角圓角（約 8 格）、底線微鼓。
- 中線沿著臉的表面彎（頭頂 → 額頭 → 鼻 → 嘴 → 下巴）；正交投影下橫線維持水平。

### 4. 側臉（面向左）

- 頭蓋＝同一個圓；臉的前緣用一串側面輪廓點（額、眉骨、眼窩凹、鼻、人中、唇、下巴凹、下巴）。
- **頭骨和下顎要分開**（使用者糾正過：之前把頭蓋圓的底部畫成下巴的一部分）：
  - 後腦圓只到後下方 55° 那點，從那裡接**後頸**，順順地往下變成脖子後緣。
  - 頭蓋圓在「下顎角 → 那點」連線以下的部分是**脖子**，不是頭。
  - 下顎：耳朵下端 → 下顎角（圓角）→ 往前到下巴。
- **下顎用陰影不用線**：下巴下面的脖子上一塊影子（前寬約 8 格、往下顎角窄到 2 格）；下顎後緣後面貼 1～2 格淡陰影。下巴壓在脖子上那圈不描線。
- 鼻子、嘴唇凸出輪廓的部分**一格一格手點**（直接改頭的遮罩），不要靠曲線算（會出現尖刺、雜點）。

### 5. 鼻子（`NT=std|up|round`）

- 位置：從**山根（眼睛中央那條線＝耳線）**到**鼻頭（鼻線）**，正面約 20 格高、在中線左邊。
- **正面＝一條線**（不是兩邊陰影）：鼻樑線往右微鼓、下段往左下收；上段淡、往下陰影色；鼻頭用深色。三種只差鼻頭：

  | 種類 | 正面鼻頭 | 側面 |
  |---|---|---|
  | 正常 std | 小勾（往下再往右，尾巴微微上收） | 鼻樑直，鼻頭平平的 |
  | 翹頭尖鼻 up | 深色尖角，尖端朝右下（使用者範例） | 鼻樑微凹，接近鼻頭才往前；鼻頭**不要太尖** |
  | 圓頭 round | 線尾接一個比較寬的圓圈（5×4，上半陰影色、下半深色） | 鼻頭圓鼓 |

- 45°：同一條線從山根往左下斜出去，再接同樣的鼻頭。
- 側面**不畫鼻孔**（使用者說不用）。

### 6. 眉毛（`brow.cjs`，`BROWCFG`）

- 3D 曲線貼在頭蓋球面上，各角度用自己的投影畫（45° 遠側那條被臉的輪廓切掉是對的）。
- 預設：耳線上 13 格，眉頭離中線 14、眉尾 50；眉峰在 55% 往上拱 5 格；眉頭粗 2.4 → 眉尾 1；後 1/4 換淡棕。
- 三組各三級＝27 種：高低（dy −18／−13／−9）、粗細（w0/w1）、彎度（arch 8.5／5／1.5）。

### 7. 嘴巴（`mouth.cjs`；側臉在 `side.cjs` 手點）

- **正面是一張手點的像素圖**（字元表，`.`＝不畫），中心欄對齊中線、嘴縫那一列對齊嘴線。
- 45° 不另外畫：把正面那張貼到嘴線附近的臉表面（z 依 x 往後彎），**每一列再往後退一點**（`DZ`）。這樣下唇、牙齒、嘴裡在 45° 會縮在上唇後面。
  - 使用者糾正過：下唇太凸、牙齒太凸 → 加大 DZ。
- **側臉嘴巴另外手點**（不能用投影，只剩一條線）：
  - 上唇往前**上翹**（斜斜往左上伸出去）。
  - 下唇短、縮在上唇後面。
  - 整體**不要太凸**（凸出人中約 2 格）。
- 種類：

  | 開關 | 內容 |
  |---|---|
  | `MT=closed` | 閉嘴（使用者範例：上唇唇峰、深色嘴縫、紅色嘴角往外下勾、下唇中間亮光） |
  | `MT=open` | 微張（使用者「新的唇形」）：上唇中間**唇珠圓圓一顆、往上翹**（淺色＋亮點），開口上緣跟著拱起、露上排牙齒、下面嘴裡深色 |
  | `ULIP=thin` | 上唇薄（只剩 2 列） |
  | `ULIP=full` | 上厚唇（多 1 列） |
  | `BIG=1` | 大嘴唇（上下唇都加厚、寬 19→23） |

- 唇珠是**往上翹**的圓，不是往下垂（使用者糾正過兩次）。
- 嘴巴大小：19×9～10 格（使用者說要大一點後定的）。

## 四、被否定的做法（不要再走）

- 用舊的 droom 人偶 sheet 當底（身體不是現行版本）。
- 900×900 向量線；用 `canvas` 畫反鋸齒的線。
- 直接拿 2× 遊戲格子（臉才 28 格寬）畫參考圖那種細節：解析度不夠。臉模是 256。
- 臉框一路平滑的蛋形、下巴收成 V 尖角。
- 45° 下顎從耳朵一路斜線收尖。
- 側臉頭蓋圓的底部混進下巴；下顎用深色線描。
- 鼻子用兩邊陰影表現（要用一條線）；側臉畫鼻孔。
- 唇珠往下垂。
- 45° 下唇、牙齒比上唇凸；側臉嘴唇太凸、下唇太長。
