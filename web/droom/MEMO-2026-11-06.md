## 使用者定案

| 項目 | 定案 |
|---|---|
| 近景投影 | 「低頭看」投影（`render(..., {cam:{proj:'look'}})`）：臉正常、往下越短、胸部從上看往前凸、腿短 |
| 近景距離／高度 | 在 0.3 格拍、0.3 格看（碰撞點＝走到她面前＝0.3 格）；玩家眼睛高 0.87 格（約她下巴）；3D 板子跟近景同比例，靠近不會忽然放大 |
| 近景方向 | 8 方向；斜前／斜後用 **25 度**出圖（`render_close.cjs F2F_OBL`；45、35 都太斜，頭像在看旁邊） |
| VR | 低頭上限 45°（`VR_DOWN`）；play.html 預設真 3D（`gl3d.js`），「🧊 3D／▦ 2D」切換 |
| 臉 | 眼睛在頭高約 56%（`EYE_Z`＝−0.8）；眼窩沿眼睛五顆挖洞、整隻眼睛在凹槽裡（`ANIME_HEAD.sock`）；眼窩照深度上陰影（`SOCK_RGB`）；鼻樑隆起 0.6（會擋到斜面遠眼的內眼角）；眉骨、顴骨收平；臉橫切面圓（`flatN` 2） |
| 近景眼睛眉毛 | 第 3 組參考圖畫法（`eyes_big.js`）：粗眼線、外眼角實心三角＋粗睫毛、大圓瞳孔＋大亮點、下眼皮外側粗短線；毛筆筆觸大眉毛 |

## 現況（哪些圖是新的臉）

- **新的臉**：`sheets_f2f/p0/` 8 方向（勻稱・圓形・D・中乳暈、波浪後髮＋長髮分兩邊、餐巾布鈴鐺、陰毛／陰唇／丁字褲、鼻子尖鼻、嘴、眉、眼睛位置）。
- **還是舊的臉**（眼睛低、沒有新眼窩）：遠景 `sheets2x/`、`parts2x/`（拆部位）、坐姿、`sheets/`（1×）、`sheets_close/`（舊 0.6 格樣品）。遠景眼睛很小、沒出眼睛圖層，看不太出來，但頭的形狀（眼窩、眉骨、顴骨、鼻樑）不一樣。
- 拆部位（parts2x）的 gbuf 沒帶眼窩深度（`sockL`），之後重出遠景時要補，不然遠景看不到眼窩陰影。

## 待辦（照使用者講過的順序）

1. 遠景用新的臉重出（sheets2x、parts2x、坐姿、頭髮／臉部圖層）——開始前先算時間給使用者看。
2. 近景其他組合（其他體型、胸型、罩杯、髮型）——目前只有一組；一組 8 方向 4 核約 8 分鐘。
3. 45 度時山根附近輪廓的小凸起（之前提過，跟鼻子一起調）。
4. 3D 裡還沒有：玩家自己的身體（`?self=1`）、舊 `sheets_close` 樣品。
5. 2D（舊畫法）板子比例沒跟 3D 統一（2D 靠近會跳一點）。

## 工作方式（使用者要求）

- 先出樣品給使用者看，確認後才全部重出。
- 合併到 `claude-2026.10` 不用再問（使用者：合併，後面不要問）。
- 臉的問題要「認真研究」：用 node 量切面（橫切／直切臉表面深度）、畫標記位置圖（`eyes` 藍、凹陷紅）先找原因，不要只調參數。量切面、出樣品的小腳本可以照 README 2026-11-05～06 段落重寫。
- 截圖在手機尺寸（Pixel 7）、看 console；`?v=` 與 `web/sw.js` CACHE 每次 bump。
