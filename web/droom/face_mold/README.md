# droom 臉模（256×256 像素，2026-11-18）

給下一個工作階段看。**畫法（怎麼畫、為什麼這樣畫、被否定過什麼）寫在上一層的 `../MEMO-2026-11-18.md`，先讀那份。**這一輪只做「臉模＋五官」的像素圖樣品，**還沒接進遊戲**（droom 身體 sheet、play.html 都沒動）。
樣品圖在 `samples/`。

## 使用者定案（照時間）

1. **畫布 256×256 像素，像素畫**：不用向量線、不反鋸齒；只用三階肉色。
   | 用途 | RGB |
   |---|---|
   | 肉色 | 242,204,177 |
   | 陰影 | 216,166,140 |
   | 深色 | 184,124,104 |
2. **外框不描線**：碰到背景的外框換成肉色（剪影平塗）。`three.py` 的 `noline()` 做這一步。
3. **臉的分段（由上到下）**：
   - A＝頭頂→耳線（眼睛中央那條線），B＝耳線→鼻線，C＝鼻線→嘴線，D＝嘴線→下巴。
   - **A 佔 3/5，B＋C＋D 佔 2/5**（頭蓋圓半徑 70、圓心 y=120、耳線＝圓心＋18；B/C/D 各 88×2/9≈19.6 格）。
   - B、C、D 各有 短 ×0.8／中／長 ×1.2（`mold6.cjs draw(kB,kC,kD)`；`samples/face_BCD_9.png`）。
4. **正面臉框**：頭蓋圓 → 兩側幾乎直直到轉折點（鼻線兩端，離中線 61）→ **直線**到嘴線（寬 43）→ 從嘴線收圓到下巴（不要尖）。耳朵在耳線上一點到轉折點。
5. **左轉 45°**（`turn45.cjs`）：正面當基準做簡單 3D（頭蓋＝球、下半臉每列＝橢圓切片）轉 45°。
   - 下顎「打角度」，不是收尖：下顎角在**頭寬 1/4**（從後腦量），高度在轉折點→下巴的 62%。
   - 下顎線要**圓弧**，不要死板的折線（耳下段微鼓、下顎角圓角、底線微鼓）。
6. **側臉**（`side.cjs`）：
   - 頭骨圓和下顎**分開**：後腦圓在後下方 55° 那點接後頸；圓在「下顎角→那點」以下的部分是脖子，不是頭。
   - **下顎不用線，用陰影**：下巴下面脖子上一塊影子（前寬後窄），下顎後緣貼 1～2 格淡陰影。
7. **鼻子**（`NT=std|up|round`；`samples/nose_3types.png`）：從**山根（眼睛中央那條線）**到**鼻頭（鼻線）**。
   - 正面：鼻樑線在中線左邊、往右微鼓再往左下收（上段淡、下段陰影色）。鼻頭：正常＝小勾、翹頭尖鼻＝深色尖角朝右下、圓頭＝5×4 的寬圓圈。
   - 側面：只有輪廓（不畫鼻孔），鼻頭不要太尖。翹頭尖鼻＝鼻樑微凹；圓頭＝鼻頭圓鼓；正常＝直。
8. **眉毛**（`brow.cjs`，`BROWCFG` JSON：dy 高低、arch 彎度、w0/w1 粗細；`samples/brow_6.png`）：貼在頭蓋球面上再投影。三組各三級（高中低 × 粗中細 × 彎中平）＝27 種。
9. **嘴巴**（`mouth.cjs` 正面／45°，側臉在 `side.cjs` 手點；`samples/lips_8.png`）：
   - `MT=closed` 閉嘴（使用者範例的嘴唇）、`MT=open` 微張（新唇形：唇珠**圓圓一顆往上翹**、開口上緣跟著拱、露上排牙齒）。
   - `ULIP=thin` 上唇薄／`ULIP=full` 上厚唇／`BIG=1` 大嘴唇（拉寬到 23 格、上下唇都加厚）。
   - 45°：下唇、牙齒、嘴裡往後退（不要比上唇凸）；側臉：上唇往前上翹、不要太凸。
   - 大嘴唇是橫向拉寬，側臉閉嘴大嘴唇的下唇還有零散點，**還沒修乾淨**。

## 怎麼出圖

在這個資料夾裡跑（輸出到目前目錄）：

```
GUIDE=0 MT=open NT=up node one.cjs front.png     # 正面（GUIDE=0 拿掉輔助線）
GUIDE=0 MT=open NT=up node turn45.cjs            # → turn45.png（左轉 45°）
GUIDE=0 MT=open NT=up node side.cjs              # → side.png（側臉，面向左）
python3 three.py front.png turn45.png side.png out.png   # 外框換肉色、三張並排 ×3
```

其他開關：`NOSE=0`／`BROW=0`／`MOUTH=0` 不畫該部位；`B=`／`C=`／`D=` 長短倍率（turn45、side）；`node mold6.cjs` 會出 `mold9/` 九張（慢）。右轉直接左右翻。
