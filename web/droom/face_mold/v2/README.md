# droom 臉模 v2（2026-11-18～19 重做，256×256 像素畫）

v1（上一層 `face_mold/`、`../MEMO-2026-11-18.md`）的臉形是錯的，這一版照使用者給的教學圖重做。**還沒接進遊戲**。

## 出圖

```
GUIDE=0 python3 outline.py OUT      # 正面 front.png、側臉 side.png（GUIDE=1 有輔助線）
GUIDE=0 python3 turn45.py OUT       # 斜臉 turn45.png（DEG=25/30/35/45，預設 30）
python3 features.py OUT             # 在上面三張貼五官 → front_f.png / turn45_f.png / side_f.png
python3 frames_demo.py OUT out.png  # 眼眶種類一覽（只畫正面、只有眼睛；KEYS=A1,B3,...；LINE=1 線稿）
python3 colors_demo.py OUT out.png  # 黑眼珠 8 色 × 瞳孔類型 3 種
```

樣品圖都在 `samples/`。

## 臉的輪廓（定案）

- 照「How to draw basic faces」量的比例（頭蓋圓直徑＝1，從頭頂量）：眉 0.63、眼 0.80、鼻＝圓底 1.00、嘴 1.09、下巴 1.25。
- **正面兩頰：從眉線（圓上）直線斜到鼻線（半寬 48），再收成 V 到下巴**（使用者紅線）。耳朵只露細細一條。
- 側臉：下半臉往前凸、後腦往後拉 1.08、脖子往前斜。
- 斜臉：正面半寬＋側臉中線做簡單 3D 再轉（`shape3d.py`）。四個角度都留著（DEG=25/30/35/45）；動畫「45 度」看起來其實接近 30°（山田式教學中線在臉寬 1/4～1/3）。
  - 斜臉耳朵：斜著朝前長，寬度＝側臉耳朵 ×EW（√sin 角度）；前緣在頭寬 0.74（EFR）、往上 14（EUP）；接臉那條線用淡色。
  - 斜臉鼻子：形狀不變、整組往前平移 NX=6 格，跑出輪廓的部分補肉色（外框不描線）。

## 使用者定案／被否定的做法

- 黑眼珠：**大、偏上**，上緣藏在上眼線下、下緣碰下眼線；橫向放在開口中間。不要照教學偏外眼角。
- 黑眼珠外框**不用黑**，用同色系深色（O）。舊的瞳孔（PT=0）不要了。
- 下眼眶要淡；眼角的線、勾不要太粗。
- 斜臉兩隻眼睛都是橢圓（遠側較窄），不是三角形。
- 側臉眼睛：前緣是**微微往前凸的圓弧**，不是斜線，前緣不描邊。
- 眉毛跟著眼睛走；側臉眉毛畫在眼睛正上方（不要投影到額頭前緣）。
- 看新設計時先給線稿（不著色）。
- **唇珠**（使用者改圖定案）：正面＝上唇中間一塊深一點的肉往上鼓（蓋過上唇上緣），下半壓進開口（淺粉一小塊＋底下深線），牙齒在兩邊；側面＝往前上翹的厚肉（outline.py／shape3d.py 唇形、features.py side_lips）。不是往下垂。
- 嘴巴：MS=小／中／大（大是手點的）、LIPS=全／下唇（上唇用很淡的肉粉色）、MT=closed／open。
- 睫毛 LASH=短／長／翹（眼尾濃）；斜臉近側那顆不動、遠側那顆和側臉往前（上翹）。眼線 EL=自然／上揚／下垂／粗框、ELC=黑／配合。眼影 SHC 先不用。
