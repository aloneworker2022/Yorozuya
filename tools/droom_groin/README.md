## 插著時陰道的反應（2026-11-09 使用者：抽插會收緊，尤其陰道口那一圈纏住陰莖；陰道勃起變長）

## 體位更正：精液流到屁股下的床上、尿是連續尿出來（2026-11-10 使用者）

使用者：她躺在床上、屁股壓在床上；陰莖是從斜前方往斜下插（正常體位），**不是在屁股下面**。所以上一節「遇到陰莖分兩道貼著陰莖流」不對，改掉：
- 流出來的精液從陰道口往後流過會陰到屁股下緣（`GROUND`＝97），在屁股下緣的床上積成一攤（`pool`，扁橢圓、量越多越寬，只畫在床＝背景格上；`st.vomit`＝那一攤的量）。
  陰莖在前面，擋住的地方不畫（`rowOut` 只是不畫在陰莖上，不再分兩道）。吐精那一大口流到屁股就進那一攤（不再一路流到畫面底）；
  抽插帶出來的滴、噴出來的小滴落在床上也進那一攤；拔出來後裡面的精液慢慢流出來。那一攤插進去也留著（重來才清）。
- 尿：不是子宮每抽一下噴一下，是**一道連續的尿**——進子宮高潮約 0.9 秒後尿出來，一次 3.8 秒（很快變強、持續、最後變弱），從尿道口落到前面的床上（強的時候尿得遠），
  落地濺幾滴、床上積一攤黃色（`st.peePool`）。一直在高潮的話隔 5～10 秒再尿一次。資訊列「尿出來了」。
