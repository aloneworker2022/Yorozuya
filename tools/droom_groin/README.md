照 droom `index.html` 的 `tint`（三階肉色）、外圈 1px 白邊上色；陰毛、陰唇肉穴跟近景眼睛 `eyes_big.js` 一樣——
**模型只給位置（陰毛 #F0F、陰唇 #FF0 標記），近景另外用曲線畫**（`groin_big.cjs`）。

- 鏡頭：她正前方 0.40 格、高 0.22 格、往下 12°，f 380，220×230（K＝2）。

## 128×128 腰部以下（`groin128.py`，2026-11-08 使用者：先低解析 128×128、只要腰部以下、照參考圖結構）

- 結構照使用者畫的結構線（棕線＝身體輪廓，藍線骨頭不畫）：腰兩條線往下到髖；大腿從髖往外往上張開、延伸出畫面，外側一道弧線；下緣一條大弧線往中間收到最底的凹口；V 字鼠蹊線從髖收到底部中間；陰唇在最底、兩條 V 線中間，陰毛在陰阜。
  V 字鼠蹊線從髖斜下到陰唇兩旁；陰毛在陰阜（倒三角，邊緣毛躁、一根根往下往外翹）；陰唇肉穴；最下面兩瓣屁股＋中間的縫；汗珠。
- 上色照 droom：肉色三階（242,204,177／216,166,140／184,124,104）＋陰唇肉瓣一階亮、鼠蹊線色、外圈 1px 白邊，平塗不抖色。
- `python3 groin128.py out.png [--hair triangle|strip|none] [--open] [--up 6] [--bg]`

## 定案（2026-11-08）：腰部以下肢體＋上色

- 線：`trace128.py`（腰中段最細、外腹斜肌圓包＋大腿擠出的肉摺、鼠蹊 S 線、大腿剖面圓鼓橢圓、大腿下緣收到胯下凹口、肚臍）。臀部先不做。
- 上色：使用者選定 `python3 trace128.py OUT.png --fill` 的樣子——droom 肉色平塗、外圈 1px 白邊；輪廓線深色（184,124,104）、剖面線／鼠蹊線陰影色（216,166,140），肉摺下一格陰影。
  成品 `groin128_color.png`。（另做的分區陰影版 color128.py 使用者不要，已刪。）

## 陰莖＋陰道子宮透視（2026-11-08）

- 陰莖：第一人稱從畫面下往上，**實心黑色剪影**（影子男，使用者選；只有外框一圈、裡面單色，不做會像透明的亮條；身體的線不畫到陰莖上；`PENIS=skin` 肉色版留著、`PENIS=none` 不畫）。
- 透視（`XRAY=1` 預設開；視角是她前方偏上斜看）：子宮往前倒趴在膀胱上＝看到頂面一頂寬扁帽子（粉紅邊、淺色內面、Y 字子宮腔），下面子宮頸小圓頭朝下；輸卵管＋卵巢；陰道從子宮頸往下、越上越窄（壓短），沒插＝一條線＋橫皺褶。
  沒插時陰道只透到陰唇上方（陰唇看得見）；`INSERT=0..1` 陰莖往裡推（0＝抵在穴口、1＝頂到子宮頸），陰道被撐開成兩側一節一節的皺褶帶、體內那段黑剪影隔著肚皮透出來。
- `python3 trace128.py OUT.png --fill [--up 6]`，環境變數 PENIS／INSERT／XRAY。陰毛 `HAIR_ON` 目前關。
- 插著（`INSERT>0.05`）：陰唇撐開——小陰唇撐成一圈包住陰莖兩側、大陰唇的肉被往兩邊推到大腿那邊（外緣一道摺＋陰影＋亮面），陰蒂在那一圈最上面；看得到的莖到撐開那圈上段（`ENT_Y`）為止。
- 陰道是圓筒：筒壁側面暗、中間亮，一圈圈往下彎的皺褶環（前半圈淡淡蓋在陰莖前面）。

## 在外面磨蹭三格（2026-11-08 使用者：透視先不做）

`RUB=1|2|3 python3 trace128.py OUT.png --fill`（RUB 時透視預設關、陰莖黑剪影）→ `rub_1.png`～`rub_3.png`
使用者紅筆：外陰唇（大陰唇）＝兩邊「( )」鼓起來的肉，小陰唇在中間；打開時外陰唇被撐開。
1. 陰莖沒碰到陰唇：大陰唇微微腫起來（( ) 鼓、外緣線＋外側陰影，不打亮），小陰唇腫、微微張開露一點紅、下段穴口。
2. 陰莖往前碰到陰唇：龜頭頂進陰唇中間（在外面、沒插進去），陰唇被撥開到龜頭兩邊、整片看得到、夾著龜頭（不蓋住也不被壓住）；開口是一個連續的杏仁形（從頂端順順張開、往下繞到龜頭兩側，上下不斷開），撥開的內面粉紅、正中一條紅；大陰唇 ( ) 更寬。
3. 陰莖往下移動摩擦撥弄：同樣撥開，龜頭往下滑、陰唇被往下拖，上方的縫拉得更長。
