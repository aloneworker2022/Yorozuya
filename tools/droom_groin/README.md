## 陰莖＋陰道子宮透視（2026-11-08）

- 陰莖：第一人稱從畫面下往上，**實心黑色剪影**（影子男，使用者選；只有外框一圈、裡面單色，不做會像透明的亮條；身體的線不畫到陰莖上；`PENIS=skin` 肉色版留著、`PENIS=none` 不畫）。
- 透視（`XRAY=1` 預設開；視角是她前方偏上斜看）：子宮往前倒趴在膀胱上＝看到頂面一頂寬扁帽子（粉紅邊、淺色內面、Y 字子宮腔），下面子宮頸小圓頭朝下；輸卵管＋卵巢；陰道從子宮頸往下、越上越窄（壓短），沒插＝一條線＋橫皺褶。
  沒插時陰道只透到陰唇上方（陰唇看得見）；`INSERT=0..1` 陰莖往裡推（0＝抵在穴口、1＝頂到子宮頸），陰道被撐開成兩側一節一節的皺褶帶、體內那段黑剪影隔著肚皮透出來。

- 插著（`INSERT>0.05`）：陰唇撐開——小陰唇撐成一圈包住陰莖兩側、大陰唇的肉被往兩邊推到大腿那邊（外緣一道摺＋陰影＋亮面），陰蒂在那一圈最上面；看得到的莖到撐開那圈上段（`ENT_Y`）為止。
- 陰道是圓筒：筒壁側面暗、中間亮，一圈圈往下彎的皺褶環（前半圈淡淡蓋在陰莖前面）。

## 插入（2026-11-08，靜態樣品 `ins_85.png`／`ins_74.png`／`ins_62.png`）

- 射精（網頁）：尿道漲滿就射，分 4 股（每股 380ms，尿道白色退一截）。插著＝內射：每股從龜頭射到子宮頸、白色灌進陰道和子宮腔（透視），拔出來肉穴口流出白色；在外面＝往上噴到下腹（肚臍下）→陰阜，第一股最遠，留下精液＋往下流一點（重來才清）。射完歸零可再漲再射。
- 射精改（使用者）：射的時候不能前後拖，陰莖每一股往前抖一下（2 格）。子宮口前的小空間（使用者：陰道和子宮口銜接的位置，陰道壁往兩邊微微鼓開一小塊；`xray_section` 的 chamber，子宮頸小圓頭從上面伸進去）：內射只積在這裡、不進子宮。射在裡面的量超過 1（空間滿）就沿著陰道／陰莖兩邊往外流，>1.5 從陰道口噴出來（口旁兩坨＋往下流），最多 3；拔出來流出的量跟著變多。

## 插著時陰道的反應（2026-11-09 使用者：抽插會收緊，尤其陰道口那一圈纏住陰莖；陰道勃起變長）

`RUB=8 PTIP=n GRIP=0..1 AROUSE=0..1 PULL=-1..1 python3 trace128.py OUT.png --fill`（只用在剖面 `xray_section`）
- `GRIP` 收緊：兩壁往裡夾住莖、咬進莖邊一節一節（皺褶那幾列咬得深）；靠陰道口那 1/3 肉壁腫厚；皺褶變深、變密（>0.5 每 2 格一道）；
  陰道口那圈肉環變厚（3 → 5 格），內緣充血紅、套緊莖＝纏住。
- `AROUSE` 陰道勃起：陰道變長＝子宮、子宮頸、輸卵管卵巢整個往上提 `LIFT`＝6×AROUSE 格（插到同樣深頂得比較淺）；龜頭上面空著那段撐開（氣球，淡粉）；壁充血變紅。
- `PULL>0` 往外抽：陰道口那圈黏著莖被拖出來（`entry_drag`：陰道口下面一截肉筒套著莖，上厚下薄、最下緣一圈紅邊；GRIP 越大拖越長）；`PULL<0` 往裡推：那圈被帶進去一點。
- 圖片條：`rub_insert_g1～g3.png`（反應 1～3 階，GRIP＝AROUSE＝階/3）、`rub_insert_g1p～g3p.png`（同上、往外抽那一下）。只重產某幾條：`ONLY=rub_insert_g1.png,... python3 gen_rub_sheets.py`。
- 網頁：插著抽送每移動 1 格反應加 1/25（約抽 3 下到第 3 階），停 1.5 秒後每秒退 0.15；往外抽之後 180ms 內用「拖出來」那條。
  子宮頸位置跟著階數往上提（`cervix0`＝60−2×階），內射的子宮口前空間跟著走。資訊列顯示「陰道收緊／纏住、變長」。
